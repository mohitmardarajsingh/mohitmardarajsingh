I'm a **CSE diploma student** deeply passionate about building technology that matters. My journey sits at the intersection of **cybersecurity**, **IoT automation**, and **practical software development** — I'm not just learning theory, I'm building real systems.

From wiring up ESP32 microcontrollers for smart automation to detecting phishing attacks using machine learning, every project I take on has a purpose: to **solve real problems through code**.

Here's what drives me every day:

- 🔐 **Cybersecurity** — Exploring secure systems, ethical hacking, and network defence through platforms like TryHackMe and real internship projects
- 📡 **IoT & Embedded Systems** — Designing hardware-software solutions using Arduino, ESP32, and sensor networks for intelligent automation
- 🌐 **Frontend Development** — Crafting responsive, pixel-perfect interfaces that users actually enjoy interacting with
- 🤖 **Basic AI & ML** — Applying machine learning in practical cybersecurity and automation contexts
- 📚 **Continuous Learning** — Staying current with DevOps workflows, Linux environments, and emerging networking concepts
- 🚀 **Innovation** — Always asking: *"Can technology solve this better?"*

> *"I don't just write code — I engineer solutions."*
